---

## THE PROBLEM — Kenapa Cepotech Harus Ada

### Masalah Universal

**"Bisnis kecil sampai menengah tidak punya sistem."**

Akibatnya:

- Data berantakan (Excel + WhatsApp + catatan kertas)
- Kerja manual (input order, kirim invoice, follow-up customer satu-satu)
- Marketing tidak terukur (posting asal, tidak tahu mana yang convert)
- Admin lambat (1 orang handle semuanya)
- Owner capek sendiri (bisnis jalan = owner harus jalan)

### Contoh Nyata di Lapangan

```
UMKM pakai Excel + WhatsApp + catatan kertas
Order dari Shopee, WA, TikTok, Instagram → tidak nyambung
Tidak ada automation → semua dikerjakan manual
Tidak ada dashboard → owner tidak tahu performa bisnis real-time
```

### Dampak

**Triliunan rupiah waktu manusia terbuang tiap tahun karena kerja manual.**

Itulah peluang Cepotech.
